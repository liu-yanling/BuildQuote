# 房建成本科目口径

> 领域知识：成本科目体系与预警口径。本技能由 s07 技能加载按需注入，也是 RAG 知识库的种子语料。

## 一级科目

| 科目 | 说明 | 常见来源 |
|---|---|---|
| 建筑工程费 | 土建/主体结构等 | 施工合同、进度款 |
| 安装工程费 | 机电/水暖电等 | 施工合同、进度款 |
| 设备及工器具购置费 | 设备购置 | 采购合同、发票 |
| 工程建设其他费 | 二类费用/间接费 | 合同、签证 |
| 预备费 | 风险/预备 | 概算 |

## 预警口径

- 默认超支阈值：实际成本超预算 5%（threshold_ratio=0.05，待产品确认）。
- 偏差 = 实际 − 预算；偏差率 = 偏差 / 预算。
- 数字由规则引擎计算（app/cost_rules.py），模型只做科目识别/归集对齐/解释引用。

## 归集来源

- 合同：合同价/暂定价，按科目分摊。
- 进度款：按已批进度款金额归集到科目。
- 签证/变更：签证金额归集到对应科目，保留来源单号。
